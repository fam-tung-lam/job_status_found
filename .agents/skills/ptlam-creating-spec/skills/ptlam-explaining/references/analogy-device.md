# The Analogy Device

This file covers analogy candidates, the mapping gate, the choice turn, and the
analogy's own checks.

## Keep a mapping ledger for every candidate

```text
literal concept -> analogy counterpart -> preserved behavior -> known limit
```

## The mapping gate

A candidate passes only when all five hold:

1. Every essential literal concept maps to one stable analogy counterpart.
2. Ownership, direction, order, state, count, lifetime, and cause are kept
   wherever they matter.
3. No analogy element stands for unrelated concepts.
4. Exact facts and limits stay literal.
5. No material rule needs a misleading mapping, an unexplained exception, or a
   second metaphor.

## Start from the domain the learner supplied

Treat a learner-supplied domain as the first candidate. Use it when it passes
the gate. When it fails, name the mismatch and offer passing alternatives. Never
swap a supplied domain quietly.

## Generate candidates when nothing supplied passes

Generate several candidates privately. Prefer an everyday domain the learner can
picture, one coherent world, faithful relationships, broad coverage, and low
explanation cost. These are starting points, not defaults:

| Concept pattern                    | Possible domain                  |
| ---------------------------------- | -------------------------------- |
| Ordered sequential work            | Recipe or assembly line          |
| Fast storage and retrieval         | Library or filing cabinet        |
| Broadcasting to unknown listeners  | Radio station or newsletter      |
| Complexity behind a simple surface | Restaurant menu                  |
| Concurrent work                    | Several cooks in one kitchen     |
| Agreed communication rules         | Introductions or phone etiquette |
| Adjustment from observed output    | Thermostat                       |
| Work spread across resources       | Traffic control                  |

## Add a choice turn only when the choice is the learner's

Use the strongest passing candidate on your own. Open a choice turn when the
learner asks to choose, rejects the current analogy, or the candidates teach
differently in ways that matter.

In that turn, show at most three passing candidates: a short domain name, one
sentence on the structural match, and the teaching trade-off. Mark the strongest
**(Recommended)**, ask which to use, and wait. Never offer a candidate that
failed the gate. If nothing coherent passes, ask the learner to narrow the goal
instead of forcing a weak analogy.

## Check the analogy

Reapply the gate to the drafted explanation. Then confirm that the story shows
the mechanism instead of decorating it, that exact facts stayed literal in the
map or the limits, and that the learner could rebuild the literal model from the
map alone.

When drafting reveals a failed mapping, do not return it. For an analogy you
chose, use the next strongest passing candidate. For a learner-supplied one,
follow the supplied-domain rule.

Finish when one analogy passes the gate, every supplied domain is honored or
rejected for a named mismatch, any learner choice is settled, and these checks
hold.
